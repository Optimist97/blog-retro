Principe : ce CMS fonctionne sans serveur. Vos modifications sont d'abord enregistrées dans ce navigateur (localStorage) pour prévisualisation immédiate.
Pour mettre en ligne, exportez les 2 fichiers ci-dessous puis remplacez-les dans votre dépôt GitHub (data/config.json et data/articles.json), commitez, et GitHub Pages republie seul.
Mise en ligne en 4 étapes :
1. Créez un dépôt GitHub (ex. ma-gazette) et poussez ce dossier.
2. Sur GitHub : Settings → Pages → Deploy from a branch → main / (root).
3. Après chaque modification dans ce CMS : Exportez → écrasez les 2 fichiers dans le dépôt → Commit.
4. Votre journal est lisible à https://VOTRE-PSEUDO.github.io/ma-gazette/.

Astuce : utilisez admin.html en local (python3 -m http.server) ou directement sur l'URL GitHub Pages : …/admin.html pour retoucher à distance puis ré-exporter.
